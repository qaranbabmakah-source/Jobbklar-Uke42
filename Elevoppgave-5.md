
# Elevoppgave 5 – Når læringsplattformen svikter

## Sikkerhet, drift og robusthet

| Tema | Forklaring og tiltak |
|---|---|
| Sikkerhetsmål | Konfidensialitet og tilgjengelighet er truet. IT må også undersøke integriteten. |
| Autentisering og autorisering | Autentisering sjekker hvem brukeren er. Autorisering bestemmer hva brukeren har tilgang til. |
| Logging | Logger viser innlogginger, tilgang og feil. IT bruker dem til feilsøking. |
| Sikkerhetskopier | Brukes til å gjenopprette slettede eller ødelagte data. |
| Redundans | En reserveserver eller ekstra database kan redusere nedetiden. |
| Prioriterte tiltak | IT stopper feil tilgang, sikrer logger, undersøker feil og gjenoppretter systemet. |

## Konklusjon

Jeg har lært at sikkerhet, logging, sikkerhetskopier og redundans er viktige for å holde en læringsplattform trygg og tilgjengelig.
